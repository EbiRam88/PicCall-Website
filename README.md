# PicCall Website

Official website for PicCall - Visual Contact Dialing Made Simple

## About

PicCall is a visual contact dialing app that makes calling your favorite contacts simple and intuitive. Instead of scrolling through long lists, see your contacts as large, easy-to-tap photo cards.

## Features

- 📸 Visual Contact Cards
- ⚡ One-Tap Calling
- 🖼️ Easy Photo Management
- 🔒 Privacy & Security
- ✨ Simple Interface
- 👥 Perfect for Everyone
