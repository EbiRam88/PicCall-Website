# Contact Images

Place contact photos here with these filenames:
- `mom.jpg` or `mom.png` - Photo for Mom
- `dad.jpg` or `dad.png` - Photo for Dad
- `sarah.jpg` or `sarah.png` - Photo for Sarah
- `john.jpg` or `john.png` - Photo for John

Supported formats: JPG, PNG, WebP

The website will automatically use these images if they exist, otherwise it will show colored avatars with initials.
